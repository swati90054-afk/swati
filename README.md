📊 Flipkart Sales Dashboard
🚀 A data analysis project that turns Flipkart sales data into easy-to-understand visual insights.
✨ Project Overview
This project explores a Flipkart sales dataset and presents key information through different charts and graphs. The goal is to make sales patterns easier to understand and help viewers compare categories, products, cities, order statuses, discounts, and payment methods.
📈 Visualizations Included
📊 Horizontal Bar Chart: Compares order value by category.
📍 Lollipop Chart: Shows quantity sold by product.
🏙️ Column Chart: Compares order value across cities.
🍩 Donut Charts: Show product unit-price contribution and payment method share.
📉 Line Chart: Tracks monthly order value trends.
🧱 Stacked Bar Chart: Compares order status across categories.
🔎 Scatter Plot: Explores the relationship between discount amount and order value.
🗺️ Heatmap: Compares city and category performance.
📦 Box Plot: Shows how discount percentages vary by category.

⚠️ Data Note
The sum of discount percentages is not the average discount rate. Also, the sum of unit prices should not be treated as profit; cost data is required to calculate profit.
